CSS 기초

웹 페이지의 디자인과 레이아웃을 담당하는 스타일시트를 배워보세요.

CSS란?

CSS(Cascading Style Sheets)는 HTML로 작성된 문서의 표시 방법을 기술하는 스타일 시트 언어입니다. 웹 페이지의 색상, 폰트, 레이아웃 등을 자유롭게 설정할 수 있습니다.

CSS 선택자와 속성

💡 알림
CSS는 선택자(Selector), 속성(Property), 값(Value)으로 구성됩니다. 중괄호 {} 안에 속성과 값을 쌍으로 작성합니다.
CSS 
/* 선택자 { 속성: 값; } */
h1 {
    color: #333333;
    font-size: 32px;
    font-weight: bold;
}

p {
    color: #666666;
    line-height: 1.8;
    margin-bottom: 16px;
}

.button {
    background-color: #3498db;
    color: white;
    padding: 12px 24px;
    border-radius: 8px;
}

CSS 선택자

HTML 요소들을 선택하여 스타일을 적용하는 방법을 알아봅시다.

다양한 CSS 선택자

⚠️ 주의사항
클래스 선택자는 점(.)을, ID 선택자는 샵(#)을 앞에 붙여야 합니다. ID는 페이지당 한 번만 사용하고, 클래스는 여러 번 재사용할 수 있습니다.
CSS 
/* 태그 선택자 - 모든 h2 요소 */
h2 {
    color: #2c3e50;
}

/* 클래스 선택자 - .intro 클래스 */
.intro {
    font-size: 18px;
    color: #555;
}

/* ID 선택자 - #header 아이디 */
#header {
    background-color: #fff;
    padding: 20px;
}

/* 자식 선택자 - nav 안의 a 요소 */
nav a {
    text-decoration: none;
    color: #3498db;
}

/* 호버 상태 - 마우스 올렸을 때 */
a:hover {
    color: #2980b9;
}

박스 모델 (Box Model)

CSS에서 모든 요소는 박스로 구성됩니다. 박스 모델을 이해하면 레이아웃을 정확하게 제어할 수 있습니다.

박스 모델의 구성 요소

✅ 팁
box-sizing: border-box;를 사용하면 패딩과 테두리를 요소의 너비에 포함시킬 수 있어 레이아웃 계산이 훨씬 쉬워집니다.
CSS 
.box {
    width: 200px;
    height: 100px;
    padding: 20px;      /* 내부 여백 */
    border: 2px solid #333;  /* 테두리 */
    margin: 16px;         /* 외부 여백 */
    box-sizing: border-box;
}

/* flexbox로 중앙 정렬 */
.center-box {
    display: flex;
    justify-content: center;
    align-items: center;
}

Flexbox 레이아웃

Flexbox는 효율적인 레이아웃을 만들 수 있는 강력한 CSS 모듈입니다.

Flexbox 레이아웃

💡 알림
Flexbox는 display: flex;를 선언한 요소를 flex container로 만들고, 그 안의 자식 요소들이 flex item이 됩니다.
CSS 
.container {
    display: flex;
    flex-direction: row;        /* 행 방향 */
    justify-content: space-between; /* 양쪽 정렬 */
    align-items: center;       /* 세로 중앙 */
    gap: 16px;
}

.item {
    flex: 1;  /* 같은 비율로 확장 */
}

/* 반응형: 화면이窄으면 세로 배치 */
@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}
