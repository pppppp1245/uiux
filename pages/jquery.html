jQuery 기초

JavaScript 라이브러리를 활용하여 효율적으로 웹 개발하는 방법을 배워보세요.

jQuery란?

jQuery는 JavaScript를 더 쉽게 사용할 수 있도록 만들어진 라이브러리입니다. DOM 조작, 이벤트 처리, 애니메이션 등을 간결한 문법으로 구현할 수 있습니다.

jQuery 로고

💡 알림
jQuery는 $ 기호로 시작합니다. 이는 jQuery 객체에 접근하는Shortcut입니다. jQuery를 사용하면 일반 JavaScript보다 적은 코드로 더 많은 기능을 구현할 수 있습니다.
JavaScript (jQuery) 
// jQuery로 요소 선택
$('.my-class')

// 일반 JavaScript와 비교
// document.querySelector('.my-class')
// ↓ jQuery로 간단하게
$('.my-class')

// 요소 숨기기
$('.box').hide();

// 요소 표시
$('.box').show();

// 애니메이션과 함께
$('.box').slideUp(500);

jQuery 선택자

jQuery는 CSS 선택자뿐만 아니라独自の 선택자도 제공합니다.

jQuery 선택자

⚠️ 주의사항
jQuery 선택자는 항상 $() 또는 jQuery()로 감싸야 합니다. 선택자는 문자열 형태로 작성합니다.
jQuery 
// 태그 선택자
$('p')           // 모든 p 요소
$('div')          // 모든 div 요소

// 클래스 선택자
$('.intro')       // .intro 클래스

// ID 선택자
$('#header')      // #header 아이디

// 속성 선택자
$('[href]')       // href 속성이 있는 요소
$("a[href*='example']") // href에 example이 포함된 링크

// 필터 선택자
$('li:first')     // 첫 번째 li
$('li:last')      // 마지막 li
$('li:odd')       // 홀수 번째 li (0부터 시작)
$('li:even')      // 짝수 번째 li
$('li:eq(2)')     // 3번째 li (인덱스 2)

이벤트 처리

jQuery로 쉽게 이벤트 처리를 구현할 수 있습니다.

jQuery 이벤트

✅ 팁
.on() 메서드를 사용하면 여러 이벤트를 동시에 바인딩하거나, 동적으로 추가된 요소에도 이벤트를 적용할 수 있습니다.
jQuery 
// 클릭 이벤트
$('.btn').click(function() {
    alert("버튼 클릭!");
});

// 더블 클릭
$('.box').dblclick(function() {
    $(this).hide();
});

// 마우스 호버
$('.menu-item').hover(
    function() { // 마우스 들어올 때
        $(this).addClass('active');
    },
    function() { // 마우스 나갈 때
        $(this).removeClass('active');
    }
);

// 키보드 이벤트
$('input').keyup(function(e) {
    console.log(e.key);
});

// on() 메서드로 여러 이벤트
$('.item').on('click mouseenter', function() {
    console.log("이벤트 발생!");
});

애니메이션 효과

jQuery의 애니메이션 메서드로 부드러운 화면 전환을 구현할 수 있습니다.

jQuery 애니메이션

💡 알림
애니메이션 메서드 뒤에 콜백 함수를 추가하면 애니메이션 완료 후 실행할 코드를 지정할 수 있습니다.
jQuery 
// 숨기기/표시
$('.box').hide(500);    // 0.5초 동안 숨기기
$('.box').show(500);    // 0.5초 동안 표시
$('.box').toggle();      // 전환 (숨김↔표시)

// 슬라이드 효과
$('.box').slideUp(300);   // 위로 접히며 숨기기
$('.box').slideDown(300); // 아래로 펴지면서 표시
$('.box').slideToggle(); // 전환

// 페이드 효과
$('.box').fadeOut(300);  // 서서히 사라짐
$('.box').fadeIn(300);   // 서서히 나타남
$('.box').fadeToggle(); // 전환

// 사용자 정의 애니메이션
$('.box').animate({
    opacity: 0.5,
    left: +=50,
    fontSize: "24px"
}, 1000, function() {
    // 애니메이션 완료 후 실행
    console.log("애니메이션 완료!");
});

AJAX 통신

jQuery로 간단하게 AJAX 통신을 구현할 수 있습니다.

AJAX 통신

✅ 팁
$.ajax()는 가장 기본적인 AJAX 메서드입니다. $.get(), $.post(), $.getJSON() 등 간단한 메서드도 있습니다.
jQuery 
// GET 요청
$.get('/api/data', function(response) {
    console.log(response);
});

// POST 요청
$.post('/api/submit', {
    name: "홍길동",
    email: "test@example.com"
}, function(response) {
    console.log(response);
});

// AJAX 기본 문법
$.ajax({
    url: '/api/data',
    method: 'GET',
    dataType: 'json',
    success: function(data) {
        console.log(data);
    },
    error: function(xhr, status, error) {
        console.log("에러 발생:", error);
    }
});

모달 창 (Modal)

모달은 사용자의 주의를 끌거나 중요한 정보를 전달할 때 사용하는 팝업 창입니다. jQuery를 사용하면 간단하게 모달을 구현할 수 있습니다.

모달 창 구조

✅ 핵심 포인트
fadeIn()과 fadeOut()을 사용하여 부드러운 애니메이션 효과를 줄 수 있습니다. is() 메서드를 사용하여 클릭한 요소가 배경인지 확인할 수 있습니다.
HTML 
<!-- 열기 버튼 -->
<button class="open-btn">프로필 편집</button>

<!-- 모달 구조 -->
<div class="modal-wrapper">
    <div class="modal-box">
        <div class="modal-header">
            <h2>프로필 설정</h2>
            <span class="close-icon">&times;</span>
        </div>
        <div class="modal-body">
            <p>변경사항을 저장하시겠습니까?</p>
            <input type="text" placeholder="닉네임을 입력하세요">
        </div>
        <div class="modal-footer">
            <button class="close-btn">취소</button>
            <button class="save-btn">저장하기</button>
        </div>
    </div>
</div>
CSS 
/* 전체를 덮는 배경 */
.modal-wrapper {
    display: none;
    position: fixed;
    top: 0; left: 0;
    width: 100%; height: 100%;
    background: rgba(0, 0, 0, 0.6);
    z-index: 9999;
}

/* 중앙에 위치하는 박스 */
.modal-box {
    position: absolute;
    top: 50%; left: 50%;
    transform: translate(-50%, -50%);
    background: #fff;
    width: 400px;
    border-radius: 12px;
    overflow: hidden;
    animation: slideDown 0.3s ease-out;
}

@keyframes slideDown {
    from { transform: translate(-50%, -70%); opacity: 0; }
    to { transform: translate(-50%, -50%); opacity: 1; }
}
jQuery 
$(document).ready(function() {
    
    // 모달 열기
    $('.open-btn').click(function() {
        $('.modal-wrapper').fadeIn(200);
    });

    // 모달 닫기 (X 버튼, 취소 버튼)
    $('.close-icon, .close-btn').click(function() {
        $('.modal-wrapper').fadeOut(200);
    });

    // 배경 클릭 시 닫기 (영역 판별)
    $('.modal-wrapper').click(function(e) {
        if ($(e.target).is('.modal-wrapper')) {
            $(this).fadeOut(200);
        }
    });
    
    // 저장 버튼 클릭 시
    $('.save-btn').click(function() {
        const nickname = $('input').val();
        alert("저장되었습니다: " + nickname);
        $('.modal-wrapper').fadeOut(200);
    });
});

🎯 실습: 확인 대화상자 만들기

삭제 확인 모달을 만들어보세요:

  • "삭제" 버튼을 클릭하면 모달이 열림
  • "확인" 클릭 시 "삭제되었습니다" 알림
  • "취소" 클릭 시 모달 닫힘
  • 배경 클릭 시에도 모달이 닫히도록 구현
