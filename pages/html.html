HTML 기초

웹 페이지의 구조를 만드는 마크업 언어를 배워보세요.

HTML이란?

HTML(HyperText Markup Language)은 웹 페이지의 구조와 내용을 정의하는 마크업 언어입니다. 웹 브라우저는 HTML 문서를 읽어 화면에 내용을 표시합니다.

HTML 문서의 기본 구조

💡 알림
HTML은 프로그래밍 언어가 아니라 마크업 언어입니다. 데이터를 표시하는 구조를 정의하는 역할을 합니다.
HTML 
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>HTML 학습</title>
</head>
<body>
    <h1>안녕하세요!</h1>
    <p>HTML을 학습하고 있습니다.</p>
</body>
</html>

주요 HTML 태그

웹 페이지에서 가장 많이 사용되는 기본 태그들을 알아봅시다.

주요 HTML 태그 목록

⚠️ 주의사항
HTML 태그는 대소문자를 구분하지 않지만, 소문자로 작성하는 것이 권장됩니다. 모든 태그는 시작 태그와 종료 태그가 짝을 이루어야 합니다.
HTML 
<!-- 제목 태그 -->
<h1>가장 큰 제목</h1>
<h2>두 번째 제목</h2>
<h3>세 번째 제목</h3>

<!-- 단락 태그 -->
<p>문단을 나타내는 태그입니다.</p>

<!-- 링크 태그 -->
<a href="https://example.com">클릭하세요</a>

<!-- 이미지 태그 -->
<img src="image.jpg" alt="이미지 설명">

<!-- 목록 태그 -->
<ul>
    <li>항목 1</li>
    <li>항목 2</li>
</ul>

폼(Form) 태그

사용자로부터 데이터를 입력받는 폼을 만드는 방법을 알아봅시다.

HTML 폼 구성 요소

✅ 팁
폼 태그의 action 속성은 데이터를 전송할 서버의 URL을 지정합니다. method 속성은 데이터 전송 방식을 결정합니다 (GET 또는 POST).
HTML 
<form action="/submit" method="POST">
    <label for="username">이름:</label>
    <input type="text" id="username" name="username">
    
    <label for="email">이메일:</label>
    <input type="email" id="email" name="email">
    
    <button type="submit">전송</button>
</form>

연습 문제

이제 배운 내용을 바탕으로 연습 문제를 풀어보세요.

문제: 자기 소개 페이지 만들기

다음 요소를 포함하는 자기 소개 페이지를 만들어보세요:

  • 제목: "나의 소개"
  • 이름과 나이를 표시하는 단락
  • 취미 목록 (순서 없는 목록)
  • 링크 버튼 (블로그 또는 SNS)
💡 도움말
<h1>, <p>, <ul>, <li>, <a> 태그를 사용하여 만들어보세요.
