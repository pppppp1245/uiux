JavaScript 기초

웹 페이지에 동적인 기능을 추가하는 프로그래밍 언어를 배워보세요.

JavaScript란?

JavaScript는 웹 페이지에 동적인 기능을 추가하는 프로그래밍 언어입니다. HTML과 CSS로 만든 정적인 웹 페이지를 JavaScript로 만들어 동적으로 변화시킬 수 있습니다.

JavaScript의 역할

💡 알림
JavaScript는 브라우저에서 실행되는 클라이언트 스크립트 언어입니다. 최근에는 Node.js를 사용하여 서버측 개발에도 사용됩니다.
JavaScript 
// 브라우저 경고창 표시
alert("안녕하세요!");

// 콘솔에 출력
console.log("JavaScript 시작!");

// HTML 요소 선택하고 내용 변경
const heading = document.querySelector('h1');
heading.textContent = "새로운 제목";

변수와 데이터 타입

JavaScript에서 데이터를 저장하고 다루는 방법을 알아봅시다.

변수의 종류

⚠️ 주의사항
var는 함수 스코프, let은 블록 스코프입니다. modern JavaScript에서는 const와 let 사용을 권장합니다.
JavaScript 
// 변수 선언
const name = "홍길동";  // 변경 불가능한 변수
let age = 25;           // 변경 가능한 변수

// 데이터 타입
const string = "문자열";    // 문자열
const number = 123;        // 숫자
const boolean = true;     // 불리언
const array = [1, 2, 3];   // 배열
const object = { name: "홍길동", age: 25 }; // 객체

// 배열 사용
console.log(array[0]);  // 1
console.log(array.length); // 3

// 객체 사용
console.log(object.name); // 홍길동

함수 (Function)

재사용 가능한 코드 블록을 만드는 함수를 알아봅시다.

함수의 구조

✅ 팁
ES6부터는 화살표 함수(Arrow Function)를 사용하여 더 간결하게 함수를 정의할 수 있습니다.
JavaScript 
// 일반 함수
function greet(name) {
    return `안녕하세요, ${name}님!`;
}

// 화살표 함수
const greetArrow = (name) => {
    return `안녕하세요, ${name}님!`;
};

// 단축형 (중괄호 생략)
const greetShort = name => `안녕하세요, ${name}님!`;

// 함수 호출
console.log(greet("홍길동")); // 안녕하세요, 홍길동님!

DOM 조작

HTML 요소를 JavaScript로 조작하는 방법을 알아봅시다.

DOM 트리 구조

💡 알림
DOM(Document Object Model)은 HTML 문서를 객체로 표현한 것입니다. JavaScript로 DOM을 조작하여 웹 페이지의 내용을 동적으로 변경할 수 있습니다.
JavaScript 
// 요소 선택
const element = document.querySelector('.my-class');
const elements = document.querySelectorAll('.item');

// 내용 변경
element.textContent = "새로운 텍스트";
element.innerHTML = "<strong>강조</strong>";

// 스타일 변경
element.style.color = "#3498db";
element.style.display = "none";

// 클래스 추가/제거
element.classList.add("active");
element.classList.remove("hidden");
element.classList.toggle("selected");

// 이벤트 처리
element.addEventListener('click', function(e) {
    console.log("클릭됨!");
});

연습 문제

이제 배운 내용을 바탕으로 연습 문제를 풀어보세요.

문제: 버튼 클릭 카운터

버튼을 클릭할 때마다 클릭 횟수가 증가하는 기능을 만들어보세요:

  • 버튼을 클릭하면 카운터 값이 1 증가
  • 현재 카운터 값을 화면에 표시
  • 카운터가 5에 도달하면 "잘했어요!" 메시지 표시
💡 도움말
addEventListener, textContent, if 문을 활용해보세요.
